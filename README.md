# 💬 Java Messenger

A simple **Java-based messaging application** with a separate client and server.

The project demonstrates basic client-server communication and messaging functionality using Java.

## 📌 About

This project is divided into two parts:

- **Messenger-server** — Handles the server-side communication.
- **message-client** — Client application used to connect and exchange messages.

The project was built to practice Java networking and client-server application concepts.

## ✨ Features

- Client-server architecture
- Multiple components for client and server
- Message communication between client and server
- Java-based implementation
- Simple messaging application

## 🛠️ Tech Stack

- **Java**
- **Java Networking**
- **Client-Server Architecture**

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/gauravtaulkar/Messager_JAVA.git
```

### 2. Open the project

Open the repository in an IDE such as:

- IntelliJ IDEA
- Eclipse
- VS Code

### 3. Run the Server

Open the `Messenger-server` project and run the server application first.

### 4. Run the Client

Open the `message-client` project and run the client application.

Connect the client to the running server to start communication.
